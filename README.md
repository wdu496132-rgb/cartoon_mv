# cartoon-mv-skill

一个可复用的 Skill：**用纯代码制作二维卡通 MV / 剧情短片**（V2.2）。

## 能做什么

给一首歌（音频 + 歌词）或一段文案，生成纯代码绘制的二维卡通视频：

- **默认 16:9 横屏**，1920×1080，30fps，MP4（H.264 + AAC）
- **多视角多机位**：18 种机位/景别（正面、侧面、3/4、背影、俯视、仰视、越肩、主观、分屏……），20 类运镜（跟拍、环绕、甩镜、冲击推近……）
- **语义分镜**：歌词/文案驱动人物、道具、环境、光影、镜头，每镜头有 `semanticReason` + `cameraReason`
- **智能时长**：有音频按 FFprobe 实测时长，无音频按语速标点估算，绝不写死 10/30/60 秒
- **12 种可切换美术风格**：治愈、赛博、美漫、日漫、水墨、国风……
- 零外部素材：角色场景全部由 SVG/CSS/Canvas 代码绘制

## 实测案例

王力宏《爱错》卡通 MV：238.83 秒原音频驱动，38 句精确歌词时间轴，
28 镜头版含走路/奔跑循环、呼吸眨眼、围巾飘动、共舞旋转，原生 16:9 撑满。

## 文件说明

- `SKILL.md` —— Skill 正文：V2.2 完整项目规范与总提示词，AI 按此执行即可开工
- `skill.yaml` —— Skill 元信息（名称、描述、分类）

## 安装

把本仓库内容放到 Muse 的 custom skills 目录即可：

```bash
cp -r . ~/workspace/custom-skills/cartoon-mv/
```

之后对 AI 说"做个卡通 MV"就会按 V2.2 这套方法开工。
